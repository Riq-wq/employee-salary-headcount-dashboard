=== MANUAL RUN COMMAND ===

To run the full pipeline manually, execute:

C:\ProgramData\anaconda3\python.exe "C:\Users\Hassan\Desktop\DATA ANALYSIS PROJECTS\employee salaries analysis\scripts\run_scheduled.py"

This will:
- Clean the raw CSV (12 rows → 11, drop duplicate, repair 2 digit slips)
- Impute 3 values with median (Bob age 30→29, Faith age -5→29, Charlie salary 61,000→59,500)
- Run 15 data-quality checks (stops on failure, nothing written)
- Write cleaned CSV, load MySQL incrementally
- Commit run state to git with headline numbers
- Exit 0 on success; non-zero on failure (publishes nothing)

After a successful run, these artifacts are updated automatically:
- data/employee_dataset_cleaned.csv          (11 clean rows)
- data/.pipeline_state.json                   (raw 12 / clean 11 / total 679,500 / mean 61,773 / median 59,500)
- reports/generate_report.py                  (recomputed from data)
- reports/Employee_Salary_Dashboard_Report.pdf (6-page report regenerated)
- reports/charts/headcount_by_city.png        (regenerated)
- reports/charts/hiring_trend.png             (regenerated)
- reports/charts/salary_by_city.png           (regenerated)
- reports/Employee Salary & Headcount Dashboard.pptx (slide deck regenerated)

Note: README.md, _profile/README.md, and Projects.jsx are NOT auto-updated by the script.
You must update those separately (as we just did for the 11-employee snapshot).
